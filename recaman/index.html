RECAMÁN

toque para começar

A cada passo n, volte n casas se puder (sem cair abaixo de zero nem num número já visitado); se não puder, avance n. Ninguém sabe se todos os números acabam aparecendo.

Sequência

Som

Imagem

Para trás = nota macia e arco embaixo; para a frente = sino e arco em cima. O drone fica preso no menor número que ainda falta (o 4 só aparece no passo 131): quando ele finalmente aparece, a harmonia se resolve.
Teclas: M controles · F tela cheia · T texto · R recomeçar.
