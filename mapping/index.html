Janela de projeção

Abre só a imagem numa janela separada. Arraste essa janela para a tela do projetor e dê dois cliques nela (ou F) para tela cheia. Os controles ficam nesta janela, com a prévia ao lado.

Superfícies

Superfície selecionada

Recorte da mídia: arraste na miniatura para usar só uma parte (ex.: tirar os controles da obra capturada). Puxe os cantos para ajustar, arraste o meio para mover.

Edição

Mouse/dedo: arraste os cantos; arraste o meio para mover a superfície.
Controle do projetor/teclado: OK/Enter troca de canto, setas movem (Shift = 10×), N = próxima superfície, E = alças, G = grade, P = imagem de alinhamento, M = painel, F = tela cheia.
