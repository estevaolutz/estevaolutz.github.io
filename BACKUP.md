# Backup de 12 de novembro de 2026

Esta branch guarda o site como estava antes da troca pelos mapas 3D e uma cópia de cada artefato apagado do Claude.

- Raiz: o site publicado até aqui (mapas 2D, apps).
- `artefatos-claude/`: cópia de cada artefato, um por pasta.
  - `*-2d`: mapas planos (Odisseia, Alexandre, Mitologia Grega, Cabeza de Vaca, Generais Romanos, Antártida).
  - `*-ipad`: versões para iPad desses mapas.
  - `*-3d`: mapas 3D, como estavam no Claude ao serem publicados no site.
  - Demais pastas: apps e obras (Medidor SPL, Dente de Leão, Dedalus, Gotas, Stalingrado 3D, Asimov Universe, Guia de Katas Shotokan, Rolando no Plenário, Quanto Custa o Poder).

Esta branch não é publicada pelo GitHub Pages; o site sai da branch `main`.
