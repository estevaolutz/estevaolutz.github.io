TRÊS CORPOS

toque para começar

Três estrelas que se atraem: não existe fórmula geral para o movimento delas, e quase sempre ele é caótico. Mas há órbitas raras que se repetem, como a dança em oito, descoberta por Moore (1993) e provada por Chenciner e Montgomery (2000). Aqui cada estrela é uma voz; os encontros próximos tocam sinos. Basta um empurrão minúsculo para a ordem virar caos.

Gravidade de Newton entre três corpos, integrada com passos que encolhem quando as estrelas se aproximam. O oito e a borboleta são órbitas periódicas: as três estrelas percorrem a mesma curva. O triângulo de Lagrange gira rígido, mas é instável e se desfaz. No problema de Pitágoras (Burrau, 1913), três estrelas paradas nos cantos de um triângulo 3-4-5 dançam caoticamente até uma ser expulsa.
Som: cada estrela é uma voz cuja nota sobe com a velocidade; quando uma estrela passa mais perto do centro, toca uma nota; encontros próximos tocam um sino (mais forte quanto mais perto); uma fuga toca o baixo. Use o empurrão no oito para ouvir a ordem se desfazer.
